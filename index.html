📌 Key Python & Pygame Reminders:

  • Variable Rules: Variable names cannot start with numbers or contain spaces. Always assign with a single =.
  • Inputs & Math: Remember to wrap input() with int() if you want to perform number addition: num = int(input()).
  • Colons & Comparisons: Every if, for, and while header must end with a colon (:).
  • Pygame Two Loops: Pygame uses an outer while loop (the main game loop) and an inner for loop to process events like key presses (for event in pygame.event.get():).
  • Pygame Captions: Change the window title using pygame.display.set_caption("My Game Title").
